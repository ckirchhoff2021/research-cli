# 🎬 Drama Studio · AI 短剧创作工坊

一个面向「短剧生成全流程」的可视化 Web 工作台：每个环节都能**人工干预、实时预览、逐条重做**，
重做时还可以**填写自然语言反馈，让 AI 按反馈调整生成**。通过 SSE 实时查看任务日志。
底层复用项目内 `skills/drama-video-creator` 的完整 pipeline。

## 启动

```bash
# 在项目根目录
bash web/drama_studio/run_studio.sh          # 默认端口 8899
bash web/drama_studio/run_studio.sh 9000     # 指定端口
```

浏览器打开 <http://127.0.0.1:8899/>。

## 创作流水线

```
💡 创意 → 📖 剧本 → 🎭 角色 → 🎬 分镜 → 🎙️ 配音 → 🎥 片段 → 🏆 成片
```

| 环节 | 可做的人工干预 | 预览 |
|---|---|---|
| 创意 | 一句话创意 + 题材/分镜数/比例/分辨率 | — |
| 剧本 | 改片名、题材、梗概、主题、风格锚点、BGM 风格；AI 重写 | — |
| 角色 | 改外观锁定描述、记忆点、音色；单独重生成定妆照 | 角色参考图（点击可放大预览；重生成自动刷新） |
| 分镜 | 改场景/动作/情绪/时长/出场角色/对白；增删镜头 | 自动生成的视频 Prompt |
| 配音 | 单镜头 / 全部生成，改对白后可重生成 | 在线试听 |
| 片段 | 单镜头 / 全部生成，可强制重生成 | 在线播放 |
| 成片 | 合成成片，或一键补齐缺失环节后合成 | 最终视频 |

## 带反馈重新生成

所有「重新生成」按钮都会弹出反馈框，**留空 = 按原样重新生成**，填写反馈 = 按反馈调整：

| 模块 | 反馈如何生效 | 示例 |
|---|---|---|
| 剧本 | 调用 LLM `refine_script`，带上一版完整剧本 + 反馈，要求只改反馈点、其余保持不变，并自动重建分镜 prompt 与定妆照 | “结局改成大团圆”“女主再强势一些”“中段加一个反转，分镜减到5个” |
| 定妆照 | 反馈追加到出图 prompt，并继续强制单人胸像构图，防止其他角色误入 | “换成白色衣服”“笑容再明显一点”“背景换成室外” |
| 配音 | 弹窗里可**直接下拉选择音色**；反馈文字可换音色（女声/男声/温柔/御姐/少女/奶奶等），也可解析为 `语速/音量/音调` 三参数，删除旧音频后重新合成。**反馈中点名角色（如“苏娘换成温柔女声”）时只改该角色，避免同镜头其他人被误改** | “苏娘换成温柔女声”“御姐音”“语速慢一点，音量大一点” |
| 视频片段 | 反馈追加到该镜头视频 prompt，自动强制重生成；角色参考图继续锁定人物一致性 | “镜头再拉近一些”“改成雨夜”“人物表情再激动” |

反馈文本通过任务接口的 `options.feedback` 字段透传到 pipeline；任务日志里会打印识别/追加结果，
未命中关键词的配音反馈不会影响生成（三参数保持 1.0）。

## 失败判定与隐私审核处理

- 视频生成脚本失败时以**非零退出码**结束；pipeline 在运行前快照输出目录，只接受**本次新生成**
  的 mp4 —— 因此 API 报错时不会再把历史旧视频误判为成功。
- 当参考图触发 `InputImageSensitiveContentDetected.PrivacyInformation`（定妆照太像真人照片）时，
  系统按三级阶梯自动降级，无需手动改定妆照：
  1. **自动卡通化定妆照**（以图生图，保持五官/服装/姿势不变，产出 `ref_<角色>_toon.jpg`，不覆盖原图）后重试；
  2. 仍触发则**去掉参考图、纯文本生成**，并加“3D CG 动画/非真人”风格前缀；
  3. 全部失败则任务明确报错，提示到角色页点「重生成定妆照」（已内置强卡通提示）。
- 成功日志会标注本次使用的是「原始定妆照 / 卡通化定妆照 / 纯文本」。
- 定妆照提示已强制 3D CG/卡通渲染质感（严禁真人照片感），从源头降低该审核问题。
- 被作废的旧产物会移动到 `segments/obsolete/` 或 `voices/obsolete/`，不会直接删除。

所有重任务由后端**全局串行 worker**执行（避免底层"取最新产物文件"的竞态），
编辑接口在项目有任务运行时返回 409，防止中途改数据。

## 技术栈

- 后端：FastAPI + Uvicorn，Pydantic，SSE（`text/event-stream`）
- 前端：原生 HTML/CSS/JS 单页应用（零构建、无 npm 依赖），暗色电影感设计
- 媒体：FastAPI `StaticFiles` 直接服务 `outputs/drama_video/` 下的图片/音频/视频
