# Image Studio · 参考图风格/特征迁移 功能设计（想法稿）

> 状态：设计讨论，未实现。目标是在现有「✨AI 创作」之外，提供一个**以目标图为基底、多张参考图为来源**的可控迁移能力。

## 1. 要解决的核心区分：风格 ≠ 特征

用户说"把参考图迁移过来"其实是两类需求，混在一起效果必然飘，先在产品层拆开：

| 模式 | 迁移什么 | 什么保持不变 | 典型说法 |
|---|---|---|---|
| 🎨 **风格迁移** | 画风、色调、光影、材质、笔触、时代感 | 目标图的主体、构图、姿态 | "把这张照片变成梵高油画 / 赛博朋克质感" |
| 🧑 **特征迁移** | 参考主体的**具体身份特征**（脸、发型、同款衣服、产品外观、IP 角色） | 目标图的场景、动作、构图 | "让图里的人穿参考图那件红裙子 / 保持这张脸" |
| 🧩 **多源组合** | 多张参考**各管一摊** | — | 图①给脸、图②给服装、图③给画风 |
| 🌪 **灵感融合** | 多张参考综合出全新画面 | 仅保留目标图构图锚点 | "参考这几张的氛围重绘目标图" |

## 2. 交互设计

### 2.1 两个明确槽位（这是和现有"多图融合"最大的区别）
- **目标图（基底，1 张）**：被改造的对象，锁定构图/主体。
- **参考图组（1–N 张）**：风格/特征来源，复用现有上传、图库、编辑器"加为参考图"入口。

布局：左栏上传区分成上下两块——上方醒目大槽位「目标图」，下方「参考图」横条（沿用已做好的 `refThumbs`/右侧 `stageRefs` 预览组件）。

### 2.1.1 防拥挤布局（关键：数量分级 + 详情浮层）
现状左栏 400px、84px 卡槽一行仅 3~4 个，多图必挤。规则：
1. **目标图独占一个 16:9 大槽位**（醒目、可换图）；参考图全部缩成 **60px 横向胶片条**，
   单行 `overflow-x:auto` 横向滚动、不换行——放多少张左栏高度都不变（直接复用右侧 `stageRefs`）。
2. **配置不常驻**：角色标签/强度/备注是低频操作，点击缩略图才弹出浮层卡片或右侧抽屉；
   小卡上只保留 序号① + 角色角标(🎨/🧑/👕) + 底部细强度刻度条。
3. **hover 才出操作按钮**（删除、拖拽排序手柄、编辑配置）。
4. **大图交给右侧舞台**：点参考图在舞台/灯箱看大图；生成后舞台是 before/after 对比滑杆。小卡只做索引。
5. UI 上限先按 **6~8 张**设计（以模型对照实验结论为准），超限给提示。

### 2.2 每张参考图是一张"可配置卡片"
点开缩略图可设置：
- **角色标签**：🎨风格源 / 🧑主体特征 / 👕服饰道具 / 📐构图光影 / 🧩局部区域
- **影响强度**：0–100 滑块（控制 prompt 权重；若模型 API 支持图权重则透传）
- **一句话备注**：如"只要这件红波点裙，不要模特的脸"
- 预览大图、移除、拖拽排序（**顺序很可能影响模型注意力**，见风险）

### 2.3 「🔍 AI 读图」——效果稳定性的关键
每张参考图旁有按钮，调**视觉模型**把图解读成结构化、可编辑的文字：

```json
{
  "style": {"色调":"暖黄低饱和","笔触":"厚涂油画","材质":"粗画布","光影":"伦勃朗侧光"},
  "subject": {"人物":"戴圆框眼镜的亚洲男性","服饰":"深灰西装"},
  "keep": ["眼镜","白衬衫"],
  "negative": ["不要保留原背景人物","不要文字水印"]
}
```

原因：多图直传时模型对"该学什么"理解不稳定；把视觉特征显式化后：
- 用户能**看到并纠正** AI 对参考图的理解；
- 文字锚点 + 原图双通道，命中率显著高于纯图；
- 人脸合规受限时，可以**只发描述不发原图**（降级路径）。

### 2.4 预设配方（降低门槛）
一键组合模式+标签+prompt 模板：`油画肖像` `动漫化` `同款穿搭` `角色一致性(锁脸)` `产品换风格` `只换背景氛围`。

## 3. 技术管线（分层，逐级降级）

```
目标图 + N 张参考图（含角色/强度/备注）
   │
   ├─[可选] 视觉模型逐张解读 → 结构化描述（同步小接口 /api/describe-image，不入任务队列）
   │
   ├─ prompt 装配器：
   │    · 模式模板（风格模板强调"主体构图不变"；特征模板强调"保留目标场景动作"）
   │    · 注入参考描述 + 用户补充 + 每图备注
   │    · 强度 → 措辞强度/参数（低=轻微倾向，高=强迁移）
   │
   ├─ 生成（doubao-seedream，image 数组；目标图置首位）
   │
   └─ 失败降级：
        人脸隐私拦截 → 提示 + 改为"描述-only"重发 / 自动裁掉非必要人脸
        多参考混淆 → 自动减到最相关 1–2 张重试
        超时     → 缩小尺寸/参考图数量重试
```

- **局部迁移**：直接复用已上线的 inpaint 框选 → 只对选区做风格/特征替换（如只换衣服不换脸、只改背景），后端在现有 `inpaint()` 上扩展"带多参考的 tile 重绘"。
- **图像预处理**：全部统一转 RGB JPEG（已有逻辑）；参考图长边压到 ~1024–1536 控成本；输出尺寸跟随目标图。
- **新增后端**：`POST /api/transfer`（异步 job）、`POST /api/describe-image`（同步快返）；产物 `outputs/17_AI图像工作室/generated/transfer_<ts>.jpg`。
- **前端**：AI 创作页 modeSeg 加第 4 项「🔗 参考迁移」，或独立第 4 主视图（倾向前者，复用 upload/反馈/SSE/图库全部现成设施）。

## 4. 预览与迭代（延续工作室"每环节可干预"的理念）

1. **Before/After 拖拽对比滑杆**：目标图 vs 结果，直观判断"构图有没有崩"。
2. **多版候选**：并发出 2–4 个任务，网格点选最优；选中版可继续微调。
3. **单张贡献预览**：对每张参考图单独跑一次 → 用户能定位"是哪张参考把画面带歪了"。
4. **强度 A/B**：同一配方自动出 30% / 70% / 100% 三档对比。
5. **反馈闭环**：复用现有 feedback modal，"脸不像参考图""风格再强一点"可直接附着重生。
6. 所有版本入图库和历史，可撤回、可送编辑器精修、可再 inpaint 补局部。

## 5. 风险与待实验（实现前先验证）

| 风险 | 应对 |
|---|---|
| doubao-seedream 多图语义不明：哪张是编辑目标？是否有图权重参数？参考图数量上限？ | 先写个 20 行脚本做对照实验（目标图放首位 vs 末位、1 vs 2 vs 3 参考），摸清楚再定 UI |
| 多主体互相污染（脸串到衣服上） | 角色标签 + 每图备注 + 描述增强 + "单张贡献预览" |
| 人脸触发 `PrivacyInformation`（短剧项目已踩过） | 上传含脸参考时前置提示；描述-only 降级；风格模式默认不发人脸原图 |
| 构图漂移、主体被改掉 | 目标图 prompt 强锁定；低强度档；局部迁移模式 |
| 视觉模型解读偏差 | 描述卡片全部可编辑，以用户确认为准 |
| 成本/耗时（读图 + 多版生成） | AI 读图按需触发不自动跑；多版候选默认 2 张 |

## 6. 建议的 MVP 切分

- **MVP（最小可用）**：目标图槽位 + 多参考上传预览 + 模式（风格/特征）+ 整体一次生成 + before/after 滑杆 + 反馈重生。
- **V1**：AI 读图结构化描述、参考图角色标签与强度、单张贡献预览。
- **V2**：多版候选、强度 A/B、局部迁移（复用 inpaint）、预设配方。
