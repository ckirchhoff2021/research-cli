# 🎨 Image Studio · AI 图像工坊

一个图像创作可视化 Web 工作台，把 **AI 生成能力** 和 **传统图像编辑工具** 合在同一个界面里：
支持上传图像、按 prompt 文生图、图生图编辑、风格迁移、带反馈重新生成、编辑预览，
并内置一个类 Photoshop 的本地图像编辑器（裁剪 / 旋转 / 翻转 / 调色 / 画笔 / 橡皮 / AI 局部重绘 / 撤销重做）。

## 启动

```bash
# 在仓库根目录
bash web/image_studio/run_studio.sh          # 默认端口 8900
bash web/image_studio/run_studio.sh 9100     # 指定端口
```

浏览器打开 <http://127.0.0.1:8900/>。

## 三大功能区

### 1. ✨ AI 创作

| 模式 | 说明 |
|---|---|
| 🎨 文生图 | 仅凭 prompt 生成；也可附加 1~多张参考图做多图融合 |
| 🖌 图像编辑 | 上传图片 + 自然语言指令（如"把背景换成海边"） |
| 🌊 风格迁移 | 上传图片 + 目标风格；prompt 自动包装为"保持主体不变，转换风格" |
| 🔗 参考迁移 | **1 张目标图（锁定构图主体）+ 多张参考图（风格/特征来源）**，支持两子模式 |

- 8 个一键风格预设：宫崎骏动漫、皮克斯3D、赛博朋克、古风国韵、油画、水彩、日系二次元、写实摄影
- 输出尺寸 2K / 3K / 4K
- **反馈重生成**：结果页点「🔄 重新生成」，弹窗里写修改意见（"色调再暖一点""笑容更明显"），反馈会追加到原 prompt
- 支持拖拽/点选上传多张参考图，可删除、可把任意结果一键加回参考图
- 生成任务串行执行，SSE 实时日志，右上角 📜 可查看

**🔗 参考迁移子模式与界面**：
- 🎨 **风格迁移**：只迁色调/光影/笔触/材质氛围，目标图人物身份、姿态、构图严格保留；
- 🧑 **特征迁移**：把参考主体的脸/发型/服饰/产品外观搬到目标图主体上，场景动作不变。
- 目标图为 16:9 大槽位（更换/移除），参考图为单行横向胶片条（带序号、可删，再多也不挤）；
- **迁移强度** 轻 30 / 中 70 / 强 100 三档；补充要求可留空；
- 图库任意图片可「🎯 设为目标」或「➕ 加为参考图」；
- 结果用 **Before/After 拖拽对比滑杆** 呈现（左原图、右迁移结果），方便判断构图是否漂移；
  产物为 `generated/transfer_<时间戳>.jpg`，同样支持反馈重生、下载、送编辑器精修。

### 2. 🖌 图像编辑（本地 Photoshop 能力，全部浏览器端完成，即时预览）

- **变换**：左右旋转 90°、水平/垂直翻转
- **裁剪**：可视化选区，四角手柄缩放、整体拖动
- **调色（7 项实时滑块）**：亮度、对比度、饱和度、色相、模糊、黑白、复古（sepia），调好再"应用到画面"
- **局部交互**：
  - 画笔（可选颜色、粗细）
  - 橡皮（传统像素擦除，擦出透明通道，画布以 Photoshop 式棋盘格显示透明区域，可导出 PNG）
- **✨ AI 局部重绘**：点「✨ AI 局部重绘」后在图上拖出/调整虚线选区 →「✍ 描述要重绘的内容」→
  输入想要的效果（如"换成红色蝴蝶结领结"），**留空则智能移除框内物体并自动补全背景**。
  后端把选区连同周边上下文送给图像模型重绘，再羽化贴回——**只有框内像素改变，框外完全不变**。
  结果自动入历史，可一键撤销；产出来自 AI，归入「AI 生成」图库。
- **历史**：撤销 / 重做 / 恢复原图
- **导出**：保存副本到服务端图库、下载 PNG、或「✨ 送 AI 继续编辑」直接带着编辑结果回到 AI 创作

### 3. 🗂 图库

按「全部 / AI 生成 / 上传 / 我的编辑」分类浏览所有图片，支持灯箱预览，并可对任意图片：
送去编辑、加为 AI 参考图、下载。

## 数据存放在哪里

按仓库 outputs 分类规范，统一保存在 `outputs/17_AI图像工作室/`：

```
outputs/17_AI图像工作室/
├── uploads/      # 上传的原图
├── generated/    # AI 生成结果（text2image_/edit_/style_ 前缀 + 时间戳）
└── edits/        # 编辑器导出的副本
```

## 技术栈

- 后端：FastAPI + Uvicorn，全局串行任务队列 + SSE，StaticFiles 媒体服务
- 前端：原生 HTML/CSS/JS 单页应用（零构建），Canvas 2D 实现编辑器
- AI：复用 `skills/image-generator/scripts/generator.py`（火山方舟 doubao-seedream 模型）
- 可靠性：生成前快照输出目录，**只接受本次新产生的图片**，API 失败明确报错，不会把旧图当新结果；
  上传/引用均有类型、大小（≤20MB）与路径穿越校验

## API 摘要

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/upload` | multipart 上传图片 |
| POST | `/api/jobs` | 提交生成任务 `{kind:"generate", options:{prompt, mode, size, feedback, images[]}}` |
| POST | `/api/save-edit` | 保存编辑器导出的 data URL |
| POST | `/api/inpaint` | AI 局部重绘 `{image:dataURL, box:{x,y,w,h}, prompt}`，prompt 留空=智能移除 |
| GET | `/api/gallery` | 三类图片清单 |
| GET | `/api/jobs` `/api/jobs/{id}` | 任务列表/详情（含日志、结果） |
| GET | `/api/events` | SSE 任务与日志事件 |

Swagger 文档：<http://127.0.0.1:8900/api/docs>。
