# Outputs 离线作品库

这是一个面向 `outputs/` 目录的本地离线展示网站。服务端实时扫描目录，前端按项目和文件类型自动分类；以后新增视频、图片、音频、文档、网页、代码或 JSON 后，只需在网页中点击“刷新”，无需重新生成 HTML。

## 启动

```bash
./outputs/_dashboard/start.sh
```

也可以在 Finder 中双击 `outputs/_dashboard/start.command`。服务会优先使用 8765；如果该端口被占用，会自动尝试后续端口，实际地址以终端输出为准：

```text
http://127.0.0.1:8765/
```

如需更换端口：

```bash
PORT=8899 ./outputs/_dashboard/start.sh
```

## 功能

- 实时扫描：每次刷新或自动同步都会重新读取 `outputs/`。
- 项目分类：自动识别视频、图片、音频、文档、网页、代码、数据和日志。
- 媒体预览：支持图片大图浏览、视频播放、音频播放和上一条/下一条切换。
- 文档阅读：内置 Markdown 渲染，支持标题、列表、表格、代码块、相对图片和文档链接。
- 网页预览：HTML 可在页面中通过沙箱 iframe 预览，也可以新窗口打开。
- 代码说明：自动提取 Python/JavaScript 的顶部说明、函数和类定义。
- 文件导航：按项目展示目录树、标签、统计、最近更新和全局搜索。
- 深度链接：项目和文件都有独立 URL，可直接跳转或刷新页面。

## 文件说明

- `server.py`：仅使用 Python 标准库的本地文件服务与目录扫描 API。
- `index.html`：单页应用入口。
- `app.js`：分类、搜索、路由、预览、Markdown 和代码解析逻辑。
- `styles.css`：页面样式。
- `start.sh` / `start.command`：启动入口。

服务只监听 `127.0.0.1`，不会把目录暴露到局域网。
