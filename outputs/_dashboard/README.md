# Outputs 离线作品库

面向 `outputs/` 的本地离线展示网站。服务端实时扫描目录并预生成摘要缓存，前端按“标签分类 → 项目目录 → 文件类型 → 文件预览”组织内容；新增文件后刷新即可出现，不需要重新生成 HTML。

## 启动

```bash
./outputs/_dashboard/start.sh
```

也可以在 Finder 双击 `outputs/_dashboard/start.command`。服务优先使用 8765，端口被占用时自动尝试后续端口，实际地址以终端输出为准。

手动预生成摘要缓存（可在空闲时执行）：

```bash
./.venv/bin/python outputs/_dashboard/server.py --build-cache --no-open
```

## 浏览结构

- 主页：展示统计、自动挑选的优质内容、语义标签入口和最近项目，只按项目聚合，不枚举散文件。
- 标签页：视频创作、图片风格、绘本图文、报告教程、网页应用、音频、小说、实验数据、脚本代码；点进去后每个项目目录以封面和缩略图展示。
- 项目页：包含封面/主视频/网页入口、内容统计、图片墙、视频墙、网页入口、文档、代码功能卡和目录树。
- 目录页：支持继续进入子目录，并按图片、视频、音频、网页、文档、代码、数据筛选。
- 文件页：支持图片大图与左右切换、视频/音频播放、HTML 沙箱预览、Markdown 阅读和代码查看。

## 摘要缓存

- 缓存文件：`outputs/_dashboard/cache.json`。
- 缓存内容：代码顶部功能说明、函数/类定义、Markdown 标题与摘要、HTML 标题/描述、JSON 字段摘要。
- 失效策略：按文件修改时间和大小自动失效；没有注释的脚本会根据导入、依赖和函数名推断用途。
- 缓存只写入 `_dashboard/`，不会修改任何原始作品。

## 技术说明

- `server.py`：Python 标准库实现的本地服务、实时扫描 API、摘要 API、Range 媒体流和本地缓存。
- `index.html` / `app.js` / `styles.css`：离线单页应用。
- 服务只监听 `127.0.0.1`，不会暴露到局域网。
