# Prompt 编写指南

搜索词：风格预设 分镜 节拍 变装 伪预告 审核 身份锁定

## 四种关键帧风格预设

与脚本 `STYLES` 字典保持一致，配套固定后缀（脚本已内置，手写时参考）：

- `3d`：皮克斯级三维渲染，CG 皮肤、大眼、毛发布料、棚拍电影光、暖色
- `anime`：今敏式写实赛璐璐，干净线稿、电影级色彩、写实背景
- `ink`：《中国奇谭》式水墨工笔重彩，石青石绿朱砂 + 水墨晕染、宣纸纹理
- `cyber`：《边缘行者》《攻壳》式赛博动漫，赛璐璐线稿、霓虹蓝洋红撞色

固定保留后缀（KEEP）要点：保留姿态/构图/服装/配饰/场景/光影；人物识别特征逐条列出；
竖版；无文字、字母、logo、水印。

## 分镜节拍

10 秒 / 6 镜头的推荐时间划分：`0-1.7 / 1.7-3.4 / 3.4-5 / 5-6.7 / 6.7-8.4 / 8.4-10`。

每个镜头写清四要素：

1. 参考图编号（图片1–图片6，按提交顺序）
2. 人物动作与表情
3. 运镜（推/拉/跟拍/低角度/慢镜）
4. 转场方式（与前后镜头衔接）

开头描述整体基调与配乐，结尾给一个定格动作。

## 常用转场语言

- 变装类：服装粒子化重组、光效扫屏、转身切换、道具抛接
- 国风类：墨痕划开、水墨晕染、鎏金粒子、云雾翻涌
- 赛博类：故障 Glitch、代码瀑布、光门穿梭、霓虹光轨
- 预告类：黑场闪白、低频重击音效、快速推拉

## 已验证的视频题材

- 丝滑变装（同一人物多重身份卡点）
- 电影伪预告（特工/黑帮/杀手/银翼杀手/武侠/国王六部类型片混剪）
- 运动热血番、3D 励志训练特辑
- 职业群像（主厨/医生/教授/建筑师/机长/咖啡师）
- 音乐 MV（爵士酒吧到万人体育场）
- 环球旅拍（城市地标、极光、沙漠、水城）
- 奇幻图鉴（龙骑士、天使、法师、雷神）、哥特暗夜、达利超现实
- 创业/商务故事、太空冒险、机甲战争
- 文人风骨、艺术流派派对、时装周、复古年代穿梭

## 审核应对经验

- 真人写实肖像 → 必然被视频接口拦截，必须先动画化
- MMA、持枪、流血、惊悚面部等画面 → 图生图输出审核也可能拦截；脚本 4 轮降级：
  正常 → 加卡通化 → 再加卡通化 → Q 版全年龄并移除武器/暴力元素
- 视频侧若仍返回某几张 `content[n]` 被拦，脚本会自动只重做那几张并整体重试一次
- 模型可能自作主张渲染拟日文/拟英文招牌，不能当真实文字使用；如介意可在 prompt 中
  强调背景纯色/无招牌并重做该镜头

## 故事模式：连贯生活短片写法

集锦模式的短板是只有视觉串联、没有故事。做生活内容时用故事模式：

- 一个故事 = 一个主角 + 一套服装 + 一处（或一条动线的）环境 + 一条情绪弧线
- 6 个节拍按「起承转合」排：开场状态 → 行动 → 沉浸/小高潮 → 温柔收尾定格
- 节拍之间必须因果衔接，例如「拉开窗帘→走进厨房→冲咖啡→端到餐桌」，不能是平行画面
- 视频 prompt 开头直接写「这是一个完整连续的故事，不是混剪、不是变装」，并复述
  服装场景全程一致，避免模型自作主张换装
- 运镜以自然跟拍、缓慢推镜、轻微手持为主；光线随故事时间推进变化
- 声音设计按节拍列环境音，配乐全片统一风格（吉他钢琴=治愈，爵士=微醺，手风琴=旅行）

已验证的生活故事选题：周末慢早晨（咖啡读书浇花）、下班后城市夜归（霓虹→小酒馆→爵士→雨后回家）、
湖畔露营（扎营→咖啡→散步→日落→篝火观星）、一个人的旅行抵达（车站→船→旅馆→推窗→老街→晚餐）、
元气居家日（晨跑→早餐→拉伸→规划）。

## 修复集锦视频的中途形象漂移

集锦模式每帧独立风格化时，中间帧容易出现脸型变圆/变胖、眉形发型微变的漂移。修复方法：

- 选出首尾或全片中形象最准的一帧作为**唯一形象锚点（identity anchor）**
- 其余关键帧全部改为「锚点图做图生图输入 + 文字描述新场景/服装/动作」，
  prompt 里逐条对齐脸型（明确写偏瘦、不变圆胖）、发际线、眉形、眼鼻、胡茬、眼镜
- 视频 prompt 额外加一句：所有镜头必须是同一张脸，中间镜头也不允许脸型五官漂移，仅服装随场景变化
- 重生成后按多个时间点抽帧验证；旧版文件备份保留，新版覆盖原路径（画廊无需改动）
