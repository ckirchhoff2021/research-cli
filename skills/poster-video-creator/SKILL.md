# 海报视频创作技能

用同一人物的多张海报/写真，批量产出「同一个演员主演」的风格化动画短视频。

## 核心管线

视频模型（Seedance，配置见 `video-generator`）**会拒绝写实真人肖像**：直接把真人照片/写实海报作为参考图会报
`400 InputImageSensitiveContentDetected.PrivacyInformation`，缩小尺寸也无法绕过。

成熟管线（已在 24 段视频上验证）：

1. 选定每个视频要用的海报（建议每段 6 张，对应 6 个镜头）
2. 用 Seedream 图生图把海报转成**明确的动画角色关键帧**：`3d` / `anime` / `ink` / `cyber` 四种风格，姿态、构图、服装、五官特征全部保留
3. 以 6 张关键帧作为 `reference_image` + 分镜 prompt 提交 Seedance，`generate_audio=True` 让模型同步生成配乐音效

关键帧按 `{风格}_{海报文件名}` 全局缓存，多个视频复用同一「风格 × 海报」组合时不重复生成。

## 两种模式

- **集锦模式（montage）**：多张不同海报 → 多重身份/场景的变装混剪，视觉冲击强，但故事性弱
- **故事模式（story）**：需要内容连贯、有故事性时使用。每个故事指定一张 `anchor` 人物锚定图，
  脚本基于同一张图生成 6 个「同一服装、同一环境、时间连续」的故事节拍关键帧
  （缓存为 `{name}__b{i}.jpg`），再按叙事脚本生成有起承转合的生活短片

故事模式任务 JSON：

```json
{
  "name": "L1_周末慢早晨",
  "style": "3d",
  "anchor": "028_nordic_cafe.jpg",
  "wardrobe": "米白家居针织开衫和浅色休闲裤",
  "beats": ["清晨拉窗帘伸懒腰", "厨房手冲咖啡蒸汽升腾", "端咖啡到餐桌坐下摊开书",
             "低头翻书阳光洒脸", "起身给绿植浇水", "窗边捧杯望向城市微笑定格"],
  "prompt": "完整叙事脚本：强调动作前后衔接、服装场景不变、自然跟拍，并列明环境音与配乐",
  "ratio": "9:16"
}
```

写故事 prompt 的要点：明确说「这是一个完整连续的故事，不是混剪/变装」；
节拍按时间顺序且动作因果衔接（上一动作的结束是下一动作的开始）；
给出情绪弧线（如疲惫被夜色治愈、陌生城市从期待到喜欢）；
用环境音（脚步、注水、风铃、篝火）+ 统一风格配乐增强生活感。

## 运行方式

准备任务 JSON：

```json
[
  {
    "name": "05_体育热血番",
    "style": "anime",
    "posters": ["041_boxer.jpg", "042_f1_driver.jpg", "043_streetball.jpg",
                "044_rock_climb.jpg", "045_ski_downhill.jpg", "046_big_wave.jpg"],
    "prompt": "分镜描述，按时间段写清每张参考图对应的镜头、动作、运镜和转场",
    "ratio": "9:16"
  }
]
```

执行：

```bash
.venv/bin/python skills/poster-video-creator/scripts/poster_video_pipeline.py \
  --tasks tasks.json \
  --poster-dir outputs/portrait_posters \
  --out-dir outputs/poster_videos/batch3
```

常用参数：`--workers 3`（视频并发）、`--key-workers 5`（关键帧并发）、`--duration 10`、
`--resolution 1080p`、`--only 名称`、`--keyframes-only`、`--dry-run`（只校验任务和缓存）。
脚本幂等：已生成的关键帧和视频自动跳过，中断后直接重跑即可续跑。

依赖同仓库的 `image-generator`、`video-generator` 两个技能及 `.env` 中的
`IMAGE_GEN_*` / `VIDEO_GEN_*` 配置。

## 关键约束

- **身份锁定**：prompt 中固定描述人物识别特征（如圆框眼镜、短寸发型、脸型、胡茬），关键帧 prompt 和视频 prompt 都要写「五官与参考图一致、同一个人」
- **不要要求文字**：模型文字渲染不可靠，标题/字幕/字母一律不要，明确写「无文字、无水印」，靠光影、服装、场景出效果
- **审核敏感内容**：武器、血腥、暴力对抗镜头容易触发输出审核；动作场景写成无伤害、无血腥的表演/训练感。若关键帧仍被拦，脚本会自动逐级降级（卡通化 → Q 版全年龄），需接受画面相应变可爱
- **风格统一**：一段视频内只用一种关键帧风格；分镜按时间轴写（如 10 秒 6 镜头：0-1.7、1.7-3.4…），并写明转场语言（粒子重组、墨痕、故障 Glitch、光效扫屏等）
- **耗时与配额**：单张关键帧 20–60s，单段 1080p 视频约 8–15 分钟；批量前先用 `--dry-run` 检查，大批量建议分批跑

更多风格预设文案、分镜节拍写法和 prompt 模板见 `references/prompt_guide.md`。
