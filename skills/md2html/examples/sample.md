# 山间笔记

> 这是一份示例文档，用于展示 md2html 技能的各种排版元素。

## 一、缘起

去年秋天，我独自走进皖南的山村，在**粉墙黛瓦**之间住了半个月。晨起看雾，暮归听雨，把所见所想记在这份笔记里。

这里的建筑讲究"天人合一"：马头墙错落有致，天井纳光聚气，*一砖一瓦皆有章法*。

## 二、村落布局

### 水系

村中水圳沿地势蜿蜒，家家门前有活水。水口处植古树、建亭阁，既是风水关锁，也是村民纳凉闲谈之所。

### 街巷

| 街巷 | 走向 | 特色 |
|------|------|------|
| 前街 | 东西 | 商铺林立，青石板路 |
| 后巷 | 南北 | 民居错落，巷窄仅容一人 |
| 水圳沿线 | 随山势 | 家家临水，浣衣洗菜 |

## 三、营造技艺

徽派三雕——木雕、砖雕、石雕——在梁枋与门楼上登峰造极。工匠口诀有云[^1]：

> 凡屋以高为贵，以深为藏。
> 厅堂宜敞，书房宜幽。

[^1]: 引自当地老匠人口述，未见于刊本。

### 木作要点

1. 选材以杉、松为主，梁柱须阴干三年
2. 榫卯相接，不用一钉
3. 雕饰题材：渔樵耕读、梅兰竹菊

## 四、代码记录

```python
def beam_ratio(span, depth):
    """梁跨深比，传统经验值约 10:1"""
    return round(span / depth, 2)

print(beam_ratio(6.0, 0.62))  # 9.68
```

## 五、随想

山居半月，最大的收获是明白了一件事：**慢即是快**。老匠人凿一个榫眼要半个时辰，急不得；但正因急不得，百年之后梁架依然严丝合缝。
