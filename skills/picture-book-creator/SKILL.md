# Picture Book Creator（绘本创作技能）

将故事素材或深度主题改编为**图文并茂的绘本**，支持两种输出模式：
- **Markdown 轻量绘本**：适合儿童故事、短故事、童话，快速产出 8~12 页带插图的 Markdown 文档
- **HTML 精排版深度绘本**：适合影视解读、历史事件、书籍深度分析，包含考据、分章文字稿（含哲思分析）、批量插图、HTML精美排版（内置4套美术风格CSS预设）

内置自包含的批量图像生成脚本（支持重试、断点续跑、超时保护），不依赖外部 image-generator 技能。

## 关键路径（本机）
- 出图通道：seedream（读项目根目录 `.env` 的 `IMAGE_GEN_*`）
- 批量脚本：本技能 `scripts/batch_generate.py`（自带 `generator.py`，自包含）
- HTML 模板：本技能 `templates/ink-style.html`（内置水墨/工笔重彩/电影写实/黑白版画 4 套 `:root` 预设，取消注释即换风格）
- 方法论文档：`references/` 目录（改编指南、提示词指南、Markdown模板）
- 输出目录：`<project-root>/outputs/<book-slug>/`
- Python 依赖：openai、requests、python-dotenv、Pillow（见 requirements.txt）
- 运行方式：任意装有依赖的 Python 3.8+；脚本会自动从当前目录向上查找 .env

## 两种输出模式选择

| 维度 | Markdown 轻量绘本 | HTML 精排版深度绘本 |
|------|-------------------|---------------------|
| 适用场景 | 儿童故事、童话、短故事、原创小故事 | 影视解读、历史事件、书籍分析、知识绘本 |
| 页数 | 8~12 页 + 封面 | 10~20 章 + 封面 + 附录/对照表 |
| 输出格式 | `.md` Markdown 文件 | `.html` 精美排版网页 |
| 文字深度 | 浅白/文学性短段落 | 深度考据 + 哲思分析块 |
| 美术风格 | 水彩/水墨/3D/扁平/油画/日系治愈（prompt配方） | 水墨/工笔重彩/电影写实/黑白版画（CSS预设+prompt） |
| 参考文档 | `references/adaptation-guide.md` `references/prompt-guide.md` `references/template.md` | 本 SKILL.md 下方工作流 |

## 通用工作流（两种模式共用的核心步骤）

### 1. 定主题与美术风格（必须确认）

首先明确：
- **绘本模式**：Markdown 轻量 还是 HTML 精排版？
- **美术风格**：询问用户选择或根据主题推荐：
  - Markdown 模式可选：中国风水彩 / 传统水墨 / 3D动画渲染 / 扁平插画 / 油画厚涂 / 日系治愈水彩（详见 `references/prompt-guide.md`）
  - HTML 模式可选：水墨丹青·写意 / 工笔重彩 / 电影写实（暗色） / 黑白版画
- **目标读者**：儿童（语言浅白）、全年龄（文学性）、成人（保留深度）

风格一旦确定，写一段 **BASE 风格前缀**（含"无任何文字水印"），所有插图 prompt 共用。角色一致性是全书质量的关键：为每个主要角色写固定的外貌档案，凡该角色出现的场景必须原样引用。详见 `references/prompt-guide.md`。

### 2. 素材准备与分镜

**Markdown 轻量模式**：参考 `references/adaptation-guide.md` 进行故事改编、选页、对话转画面，规划每页的场景要点。

**HTML 深度模式**：
- 考据存档：必要时抓取权威来源（维基/官网/分集剧情），写入 `refs/plot-verification.md`
- 规划章节结构：序章（引子）→ 线索总览 → 主体章节 → 人物论 → 高潮 → 终章（结局对照+哲思）→ 附录

**分镜原则**：
- 一页/一章节一画面：只表现一个清晰瞬间，不塞多个情节
- 封面优先但最后生成：封面通常主角同框+核心意象，等内页角色形象稳定后再生成
- 文字先行：先写文字内容，再根据文字提炼画面

### 3. 编写插图 Prompt

**Prompt 总公式**：
```
风格锚点（固定，逐字复用） + 角色档案（固定，如涉及） + 场景画面描述（每页不同）
```

详见 `references/prompt-guide.md` 的场景描述技巧。

**批量出图格式**：整理成 JSON 数组供脚本使用：
```json
[
  {"name": "01-cover", "prompt": "..."},
  {"name": "02-scene1", "prompt": "...", "image": "/optional/reference.jpg"}
]
```
- `name`：文件名（不含扩展名），建议使用 `两位序号-场景名` 格式
- `prompt`：完整的插图提示词
- `image`（可选）：提供时走图生图/风格转换，否则纯文生图

### 4. 批量出图

```bash
cd <project-root>
.venv/bin/python skills/picture-book-creator/scripts/batch_generate.py <prompts.json> --out outputs/<slug>/images --size 2K
```

脚本特性：
- 120s 超时保护、3次指数退避重试
- 已存在文件跳过（支持断点续跑）
- 长批次可放后台运行
- 每张图输出日志带耗时和文件大小，便于排查

尺寸选择：内页默认 `2K`；印刷级需求用 `3K` 或 `4K`。

### 5. 合成输出

- **Markdown 模式**：按 `references/template.md` 结构撰写 Markdown，图片用相对路径 `images/xx.jpg`
- **HTML 模式**：使用 `templates/ink-style.html` 模板，替换占位内容，复制 `<section>` 块添加章节。修改 `:root` 中的 CSS 变量即可切换美术主题。

### 6. 验证（不可省）
1. 检查所有生成图片：抽查至少2张，确认风格到位、关键特征保留、无崩坏/水印/现代元素
2. 核对文件数量：`ls outputs/<slug>/images` 确认文件数与 prompt JSON 条目数一致
3. Markdown/HTML 中所有 `<img src>` / `![]()` 路径与实际文件名一一对应
4. 本地起 HTTP 服务器预览最终效果（`python3 -m http.server`）

## Markdown 轻量绘本工作流详解

适合儿童故事、短故事、童话等轻量内容。

### 快速流程
1. 理解素材，确定页数（8~12页+封面），选定 `references/prompt-guide.md` 中的风格配方
2. 设定角色档案，编写每页分镜表（页码/场景名/画面内容/文字要点）
3. 按公式撰写所有 prompt，整理为 JSON
4. 批量出图（先内页后封面）
5. 图片重命名归档，按 `references/template.md` 撰写 Markdown
6. 验证后汇报

### 质量要点
1. **一致性高于单张惊艳**：风格锚点与角色档案逐字复用，不随意改写
2. **写瞬间不写过程**：提示词描述具体可视瞬间，不是抽象剧情
3. **文字与图互补**：图已表达的情绪文字不复述，文字负责内心/对话/时间流逝
4. **儿童向语言**：短句、拟声词、具体名词，避免抽象形容词

详见：`references/adaptation-guide.md`、`references/prompt-guide.md`、`references/template.md`

## HTML 精排版深度绘本工作流详解

适合影视解读、历史事件、书籍深度分析、知识绘本等复杂内容。已在《大明王朝1566》《权力的游戏》等作品验证通过。

### 章节结构推荐
序章（引子/悬念） → 线索总览 → 主体章节（每章一事，带「哲思」块） → 人物论（每人：性格底色+行为方式+结局） → 高潮章节 → 终章（结局对照表 + 核心洞见/哲思） → 附录（人物索引/对照表）

每章结构：
- 章节编号（中文数字）
- 章节标题
- 正文段落（关键人物/概念加粗强调）
- 「◈ 哲思」块：把内容影射到现实的思考
- 插图卡（含图注+可展开查看prompt）

### HTML 模板使用说明

模板路径：`templates/ink-style.html`

**切换美术风格**：取消注释 `:root` 下方对应风格的预设块即可覆盖默认水墨风格。4种内置预设：
1. **水墨丹青**（默认）：宣纸底色、朱砂印章、宋体标题，适合中国历史/古风主题
2. **工笔重彩**：楷体、暖金色调，适合古典/华丽主题
3. **电影写实（暗色）**：深灰背景、无纹理、无衬线字体、金色/冰蓝强调色，适合美剧/电影/黑暗奇幻主题
4. **黑白版画**：高对比度黑白，适合纪实/历史/版画风格主题

**模板占位符**：替换 `{书名}`、`{副标题}`、`{美术风格}`、`{N}` 等占位内容；章节复制 `<section>` 块；图片放 `images/` 相对目录。

**表格支持**：结局对照表、人物表使用 `<table>` 标签，模板已内置斑马纹和表头样式。

### 深度绘本质检清单
- [ ] 每个章节都有「哲思」块，提供现实映射思考
- [ ] 关键事件与原作/史实一致（考据存档可溯源）
- [ ] 插图与章节情绪匹配，不是随便配图
- [ ] 人物结局/命运表格完整准确
- [ ] 所有图片路径正确，可正常加载
- [ ] CSS 风格与主题契合（黑暗主题配暗色预设，历史主题配水墨）

## Pitfalls（已踩过的坑）
- **openai client 默认超时 600s**：单张 API 调用偶发卡住会挂死整个批次且无报错。batch_generate.py 已显式设置 `timeout=120.0`，勿删
- **不要盲试 401 的 key**：出图 401 先报告用户检查 `.env`，勿反复调用
- **提示词里不要要求写字**：模型生成的文字通常是乱码，书名/标题由 HTML/Markdown 承担
- **HEIC 输入先转换**：`sips -s format jpeg in.heic --out out.jpg`
- **批量脚本日志必须 `flush=True`**：否则后台轮询看不到进度（脚本已处理）
- **角色描述必须具体可辨识**：不用"漂亮的衣服"这类模糊词，要写"身穿素白长袍""金色毛发"等具体特征
- **封面最后生成**：封面需要主角同框，等内页角色形象稳定后再生成，一致性更好
