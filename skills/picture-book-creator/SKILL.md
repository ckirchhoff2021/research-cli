# Picture Book Creator（绘本创作技能）

将故事素材改编为**Markdown 格式绘本**：每一页 = 一张高清插图 + 一段故事文字，全书插图风格统一、角色形象一致。本技能复用 `image-generator` 技能的图像生成脚本完成配图。

## 核心产出

```
outputs/<书名>绘本/
├── <书名>绘本.md      # 绘本正文（Markdown）
└── images/            # 全部插图
    ├── 00_封面.jpg
    ├── 01_<场景名>.jpg
    ├── 02_<场景名>.jpg
    └── ...
```

## 工作流程（六步）

### 第 1 步：理解素材，确认绘本方案

先通读用户提供的素材（剧本、故事、主题描述，或对话中已有的创作内容）。明确三件事：

1. **故事主线**：起承转合各是什么？高潮在哪一页？
2. **主题落点**：故事想传递什么（如"坚持""传承""勇气"）？结尾如何点题？
3. **目标读者**：儿童（语言浅白、句子短）、全年龄（文学性强）、成人（可保留深度）？

如果素材缺失关键信息（如只有主题没有故事），先快速创作故事梗概再继续；如果用户已给出完整剧本，直接改编，不要重写剧情。

确定**页数**：一般 8~12 个场景页 + 1 张封面。页数由故事节奏决定——每个关键转折点一页，不为凑数拆分平淡段落。

### 第 2 步：设定风格锚点与角色档案（保证全书一致性的关键）

图像模型每次调用都是独立的，**没有全局记忆**。要让十几张图看起来像同一本绘本，必须把"一致性"写进每一条提示词：

**风格锚点**：写一段固定的风格描述（约 50~80 字），所有插图提示词的开头或结尾都完整附上它。包括：画种（水彩/水墨/油画/3D 渲染/扁平插画）、色调、光影、构图气质。

**角色档案**：为每个主要角色写一段固定的外貌描述（毛色、服装、体型、标志性特征），凡该角色出现的场景，提示词中必须原样引用这段描述，不得随意改写。

示例（来自《心灯》绘本，中国风水彩）：

> 风格锚点：中国风水彩绘本插画，柔和的暖色调，水墨晕染的天空与山峦，细腻的笔触纹理，电影级构图，光线温暖，画面干净治愈，无文字无水印。
>
> 孙悟空档案：身穿素白长袍的孙悟空，金色毛发，头戴无形箍（额头干净），手持金箍棒，眼神明亮而略带沧桑。
>
> 小石头档案：一只瘦小的幼年猴子，浅棕色绒毛，大眼睛，膝盖贴着树叶绷带，怀里抱着一捆柴火。

更多风格配方与提示词写法见 `references/prompt-guide.md`。

### 第 3 步：分镜——为每一页规划场景与图注

输出一张分镜表（不必给用户看，自己执行用），每行包含：

| 页码 | 场景名 | 画面内容 | 对应文字要点 |
|------|--------|----------|--------------|
| 00 | 封面 | 主角同框 + 书名意象 | —— |
| 01 | 灵山封佛 | 悟空受封，眼神迷茫 | 取经功成却若有所失 |
| ... | ... | ... | ... |

分镜原则：

- **一页一画面**：每页插图只表现一个清晰的瞬间（一个动作、一个表情、一次对峙），不要把多个情节塞进一张图。
- **封面优先**：封面通常是主角同框 + 核心意象（如"灯"），色调最能代表全书气质。
- **文字先行**：先写每页的故事文字，再根据文字提炼画面。文字是绘本的主体，插图服务于文字的情绪。
- **避免纯对话页**：全是人物对话的场景难以入画，改编时把对话转化为动作与画面（详见 `references/adaptation-guide.md`）。

### 第 4 步：生成插图（并行 + 分批）

使用 image-generator 技能的脚本生成图片。**必须在项目根目录执行**（脚本依赖根目录的 `.env` 与 `.venv`）：

```bash
.venv/bin/python skills/image-generator/scripts/generator.py --prompt "<完整提示词>" --size 2K
```

- 提示词 = 风格锚点 + 角色档案（如涉及）+ 场景画面描述，写成一条连贯的单行中文描述。
- 尺寸默认 `2K`（绘本内页足够清晰）；用户明确要求更高清晰度时用 `3K`/`4K`。
- **并行分批**：每批同时发起 3 个生成调用，批次之间互不依赖，全部完成后再发下一批。9~12 张图通常 3~4 批完成。
- 脚本会把图片保存到 `skills/image-generator/outputs/dream_<时间戳>.jpg`，并在输出中打印 `Saved to: <绝对路径>`。**记录好每张图对应的生成顺序**（按调用顺序与输出顺序一一对应）。

**失败重试**：某张图生成失败时，先重试一次（可能是网络波动）；连续失败再检查报错。重试仍失败时调整提示词（如去掉可能触发审核的词）后重试，同一场景最多重试 3 次。

### 第 5 步：整理图片目录

在项目根目录创建 `outputs/<书名>绘本/images/`，把生成的图片按页码顺序**移动并重命名**：

```bash
mkdir -p "outputs/<书名>绘本/images"
mv skills/image-generator/outputs/dream_xxx.jpg "outputs/<书名>绘本/images/00_封面.jpg"
mv skills/image-generator/outputs/dream_yyy.jpg "outputs/<书名>绘本/images/01_<场景名>.jpg"
# ... 依此类推
```

命名规则：`两位序号_中文场景名.jpg`（如 `00_封面.jpg`、`03_花果残灯.jpg`），序号与绘本页码一致，方便排查和增删页。

### 第 6 步：撰写绘本 Markdown

按 `references/template.md` 的结构撰写 `outputs/<书名>绘本/<书名>绘本.md`：

- 图片用**相对路径**引用：`![场景名](images/01_场景名.jpg)`，保证绘本目录整体拷贝后仍可显示。
- 每页结构：`## 第N页 · 场景名` → 插图 → 故事文字 → `---` 分隔。
- 语言按目标读者改写：儿童绘本每页 2~5 句、多用拟声词与对话；文学向绘本可保留抒情段落。
- 结尾点题：最后一页之后加一段"尾声/寄语"，把主题升华成一句可以被记住的话。

完成后**逐张验证**插图文件存在且非空（`ls -la` 检查 images 目录），并向用户汇报：绘本路径、插图清单表格（页码/场景/文件名）、内容概要。

## 质量要点（来自实战经验）

1. **一致性高于单张惊艳**：宁可每张图 80 分但风格统一，不要单张 100 分但画风跳脱。风格锚点与角色档案一字不改地复用。
2. **提示词描述"瞬间"而非"剧情"**：写"小猴子用身体挡住风，护住一盏油灯"，不写"小猴子很勇敢地保护灯火"。画面要具体、可视。
3. **文字与图互补而非重复**：图已表达的情绪，文字不必复述；文字负责图表达不了的内心、对话与时间流逝。
4. **封面是最后一批生成的**：封面往往需要主角同框，等内页角色形象稳定后再生成封面，一致性更好（生成顺序可调整为：内页 → 封面，但文件命名仍按 00 开始）。
5. **输出位置**：所有产物放在项目根目录 `outputs/` 下，不散落其他目录。
