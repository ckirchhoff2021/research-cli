# 提示词指南：风格锚点与角色一致性

## 一、提示词总公式

每条插图提示词 = **风格锚点（固定）+ 角色档案（固定，如涉及）+ 场景画面（每页不同）**

三部分写成一条连贯的中文单行描述，长度 80~150 字为宜。风格锚点与角色档案**逐字复用**，绝不改写——这是全书画风统一的唯一保障。

```
示例（《心灯》第三页）：
"中国风水彩绘本插画，柔和暖色调，水墨晕染山峦，细腻笔触，电影级构图，治愈画面，无文字。
一只瘦小的浅棕色幼猴，大眼睛，膝盖贴着树叶绷带，怀抱一捆柴火；
暮色中的花果山，枯桃树与哑瀑前，白须老猴守着一盏将熄的油灯，幼猴正把柴火递向灯火。"
```

## 二、风格锚点配方库

以下配方均经过实测，可直接取用或微调。一本书只用一个配方。

### 1. 中国风水彩（默认推荐，适合神话/古风/温情故事）
> 中国风水彩绘本插画，柔和的暖色调，水墨晕染的天空与山峦，细腻的笔触纹理，电影级构图，光线温暖，画面干净治愈，无文字无水印

### 2. 传统水墨（适合写意、禅意、留白感强的故事）
> 中国传统水墨绘本插画，宣纸质感，浓淡干湿的墨色层次，大面积留白，淡彩点染，意境悠远，构图疏朗，无文字无水印

### 3. 3D 动画渲染（适合活泼的儿童故事、动物主角）
> 皮克斯风格3D渲染绘本插画，柔和的全局光照，鲜艳的饱和色彩，圆润可爱的造型，细腻的材质质感，景深虚化背景，温暖欢快，无文字无水印

### 4. 扁平插画（适合低幼认知类、科普类绘本）
> 现代扁平风格儿童绘本插画，大色块几何构图，明快的对比色，简洁圆润的造型，无渐变无描边，图案化背景，活泼童趣，无文字无水印

### 5. 油画厚涂（适合史诗感、成长主题、情绪浓烈的故事）
> 油画质感绘本插画，厚涂笔触，温暖的金色光影，浓郁的色彩层次，戏剧性明暗对比，古典构图，画面庄重而有力量，无文字无水印

### 6. 日系治愈水彩（适合日常、友情、自然主题）
> 日系治愈系水彩绘本插画，清透的淡彩，柔和的光斑，细腻的植物与云朵细节，明亮通透的色调，温柔安静的氛围，宫崎骏式的自然感，无文字无水印

## 三、角色档案写法

每个主要角色一段，包含四要素：**物种/身份 + 主色 + 服装/标志物 + 气质**。约 30~50 字。

```
孙悟空：身穿素白长袍的孙悟空，金色毛发，额头干净无金箍，手持金箍棒，眼神明亮而略带沧桑
小石头：一只瘦小的幼年猴子，浅棕色绒毛，大眼睛，膝盖贴着树叶绷带
老猴：白须佝偻的老猴子，披着打补丁的褐色短褂，手拄一根桃木拐杖
```

注意：

- 服装颜色、毛色等**具体到可辨识**，不用"漂亮的衣服"这类模糊词。
- 角色成长带来的形象变化（如受伤、获得信物），把变化点写进档案的固定描述，后续页全部沿用。
- 同框多角色时，把各自档案依次写入提示词。

## 四、场景画面描述技巧

1. **写瞬间，不写过程**："幼猴用身体挡住风，护住灯芯" ✓；"幼猴努力保护灯火" ✗
2. **写可视元素**：光线（暮色/晨光/火光）、天气（雾/雪）、道具（柴火/油灯）、动作、表情。
3. **情绪靠画面传达**：迷茫 = "望着远方一动不动"；坚定 = "攥紧柴火，挺直腰板"。
4. **构图提示**：需要气势用"仰视/广角"，需要亲密用"特写/平视"，封面常用"主角同框的对称构图"。
5. **负面内容**：避免血腥、恐怖描述；反派用"黑影/雾气/阴影"等抽象化表现更安全也更有意境。

## 五、封面提示词要点

- 主角同框 + 核心意象（书名的视觉化，如"灯""路""种子"）。
- 留出视觉中心，色调代表全书气质。
- 不要在提示词里要求写字（模型生成的文字通常是乱码），书名由 Markdown 标题承担。

## 六、尺寸与批次

- 内页默认 `2K`；用户要求印刷级时用 `3K` 或 `4K`。
- 每批并行 3 个调用；先内页后封面（封面需要角色形象最稳定）。
- 生成脚本输出 `Saved to: <路径>`，按调用顺序记录路径，便于后续重命名归档。
