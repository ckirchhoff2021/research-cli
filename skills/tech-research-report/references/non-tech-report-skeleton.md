# 非技术主题详细报告骨架（心理/健康/生活类知识）

2026-08-21《情绪修复与心态调整指南》验证。用户对非技术主题要求"详细的报告"时使用此骨架；完整流水线（检索 → 交叉验证 → MD → 概念图 → HTML + 渲染验证）不降级。注意：本文件挂在 tech-research-report 下，但 tech-report-writing 技能（同类、更细的五步流程）同样适用——两者内容重叠，建议合并。

## 章节骨架

1. **背景：为什么这么难/杀伤力这么大** — 机制解释（生理层 + 心理层），给读者"不是你的错"的去个人化；最常见陷阱用对比表
2. **原理：科学框架** — 主流理论模型（如 Ellis ABC、Gross 情绪调节过程模型），每个模型配一句话核心结论 + callout 框
3. **方法工具箱** — **按时间尺度分层**（即刻 0-10 分钟 / 当日消化 / 针对性策略 / 长期建设），每层一个表格（方法/操作/原理）；即刻层必须给"铁律"（明确不做什么）
4. **实战流程** — "今天遇到 X，全天怎么走"的时间线代码块，可照抄执行
5. **常见误区表** — 误区 vs 真相两列
6. **何时寻求专业帮助** — 健康/心理类主题必备，给明确边界条件（如持续 2 周以上）+ "求助不是脆弱"
7. **核心结论（一页纸版本）** — 编号要点 ≤7 条，callout 框
8. **注意事项（诚实性声明）** — 非技术主题尤其需要：科普简化标注（如"90 秒法则"）、数据为转述未核对原文、流行实践缺乏严格实证（如灰岩法）、不构成专业建议
9. **参考资料** — 按主题分组，知乎条目带作者 + 链接 + 赞数；原始文献单列并标注"正文转述所本，建议二次查证"

## 渲染验证的兜底路径

- 首选 `browser_navigate` + `browser_vision` 检查重叠/裁剪/悬空箭头。
- **browser_vision 连续超时时**，改用 `browser_console` DOM 几何检查：用 JS 遍历 `svg.querySelectorAll('rect')`，校验每个 `x+width ≤ viewBox 宽`、`y+height ≤ viewBox 高`，两两检测重叠（矩形相交判定），再抽查 `<text x>` 是否越界。这是本次会话验证有效的替代路径，不是"放弃验证"。
- 视觉检查发现的箭头断链/悬空问题（两段箭头不相连）：直接合并为一条折线 `path`（`M x1 y1 L x_mid y_mid L x2 y2`），改完重验。

## 检索措辞组合（心理类示例）

- 理论名中文："情绪调节 认知重评"、"反刍 内耗 怎么办"
- 场景措辞："遇到糟心的人 怎么调整心态"、"快速平复情绪 方法"
- 机制措辞："杏仁核劫持 前额叶"、"表达抑制 认知重评 实验"
- ≥3 组不同措辞；生理机制方向单独补一轮检索。

## 诚实性声明可复用句式

- "'XX 法则'为科普简化（常归于……），非精确生理常数；合理内核（……）成立。"
- "生理数据均来自知乎答主转述，未核对原始文献，仅作方向性参考。"
- "XX 法为流行心理学实践，针对特定人群的有效性缺乏严格实证，作为策略选项参考。"
- "信源中存在机构营销内容，本报告仅采用方法论描述，已剔除广告导向表述。"
- "本报告为科普整理，不构成专业诊疗建议。"
